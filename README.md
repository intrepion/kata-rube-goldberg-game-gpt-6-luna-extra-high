# Long Way Around

A small, self-contained Rube Goldberg puzzle game. Build a chain of cause-and-effect parts, then run the machine to see where the sequence succeeds or breaks.

## Play

Open `index.html` in a modern browser. Pick a part and click an open station, or drag the part onto a station. Click an installed part to return it to the tray. Each part shows the kind of nudge it needs and the nudge it makes; connect those signals from the starting event to the goal. Run the machine to animate the chain and unlock the next puzzle.

The three puzzles progress from ringing a bell, to making toast, to lighting a lamp. No install or build step is needed.
